# マリオカートワールド カスタムビルダー

マリオカートワールドのドライバーとマシンの組み合わせを選択し、合計ステータスをグラフィカルに表示するWebアプリケーションです。

## ページ構成

- **性能一覧**: 全ドライバー・マシンの性能を一覧表示
- **カスタムビルダー**: 組み合わせを選択して合計性能を確認
- **パレート最適**: 特定条件下での最適な組み合わせを探索

## 機能

- 🏎️ **ドライバー選択**: 50種類のドライバーから選択（画像付き）
- 🚗 **マシン選択**: 40種類のマシン（カート・バイク）から選択（画像付き）
- 📊 **ステータス表示**: 選択した組み合わせの合計値をグラフィカルに表示
  - スピード（スムーズ路面）
  - スピード（ラフ路面）
  - スピード（水中）
  - かそく
  - おもさ
  - まがり
- 🎨 **モダンUI**: shadcn/uiを使用した美しいインターフェース（プライマリカラー：ブルー）
- 🌓 **ダークモード対応**: ライト/ダークテーマの切り替え

## 技術スタック

- **フレームワーク**: Next.js 15.3.4 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS v4
- **UIコンポーネント**: shadcn/ui
- **グラフ**: Recharts
- **フォーム**: React Hook Form + Zod

## セットアップ

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev
```

http://localhost:3000 でアプリケーションにアクセスできます。

## 開発

```bash
# 開発サーバー（Turbopack使用）
pnpm dev

# ビルド
pnpm build

# プロダクションサーバー
pnpm start

# リント
pnpm lint
```

## プロジェクト構造

```
src/
├── app/                # Next.js App Router
│   ├── layout.tsx     # ルートレイアウト
│   └── page.tsx       # メインページ（ビルダー）
├── components/        
│   ├── ui/            # shadcn/ui コンポーネント
│   ├── driver-selector.tsx  # ドライバー選択
│   ├── machine-selector.tsx    # マシン選択
│   └── stats-display.tsx       # ステータス表示
└── lib/
    ├── stats.ts       # ドライバー・マシンのデータ
    └── utils.ts       # ユーティリティ関数
```
